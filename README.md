# Algorithm Visualizer

A better visualization of different algorithms made with React.
So far there are 3 segments

- Pathfinder
- Sorting Algorithms
- Binary Search Game

I have implemented a total of `12 algorithms` so far. And will try to add more later.

## Algorithms implemented

- BFS
- Dijkstra
- A star
- Recursive Maze Creation
- Bubble sort
- Selection sort
- Insertion sort
- Heap sort
- Merge sort
- Quick sort
- Binary Search
